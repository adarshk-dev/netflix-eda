# Project 1 - Netflix EDA

Exploratory Data Analysis on the Netflix Movies & TV Shows dataset.

## Dataset
Source: https://www.kaggle.com/datasets/shivamb/netflix-shows

## Tools Used
Python · Pandas · NumPy · Matplotlib · Seaborn · Google Colab

## What's Inside
- Data loading and inspection (8807 rows × 12 columns)
- Data cleaning (missing values handled, datetime conversion)
- 5 EDA questions answered with Pandas
- 6 visualizations (bar, pie, line, horizontal bar, histogram, genre chart)
- 5-point Insights Report
- Most surprising finding noted

## Key Findings
- Movies make up 69.6% of Netflix content vs 30.4% TV Shows
- Netflix grew nearly 5x between 2016 and 2019 (418 to 1,999 titles)
- USA, India and UK are the top 3 content-producing countries
- International Movies is the #1 genre with 2,752 titles
- Content additions dropped after 2019 likely due to COVID-19 production slowdowns
